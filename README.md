# AI Based Pulp Capping - Enterprise Suite

This repository contains the complete Android application, Backend integration, and full Automation test suites.

## 🚀 Project Overview
- **App Package**: `com.saveetha.aipulpcapping`
- **Frontend**: Kotlin, Jetpack Compose, MVVM
- **Backend**: Firebase Authentication, Firestore, Cloud Storage
- **Local DB**: Room Persistence Library (SQLite)
- **CI/CD**: GitHub Actions (Build, Test, Report, Deploy)

## 📁 Repository Structure
- `/app`: Android Application Source Code.
- `/automation`: Mobile E2E Automation Framework (Appium + TestNG).
- `/web_automation`: Web E2E Automation Suite (Selenium + Node.js).
- `/Vulnerability Test Results`: Professional Security Audit & Executive Summary.
- `/.github/workflows`: Automated pipelines for CI/CD and Security scanning.

## ✅ Quality Assurance & Testing
- **Unit Tests**: Integrated in Android project.
- **Load Testing**: 100 Virtual Users, 350 RPS Performance Baseline.
- **E2E Testing**: 400+ Test Cases covering all major modules.
- **Reporting**: Automated Excel and HTML report generation.
